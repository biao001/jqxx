2号的核心任务是：**给5号、6号准备疲劳检测算法用的数据，不负责训练模型。**

也就是说，2号要做的是：

```text
找数据 → 看视频 → 标注疲劳类别 → 整理成统一CSV → 划分训练/验证/测试集 → 交给5号、6号
```

**2号要标注哪些数据集**

建议 2号 负责这些疲劳检测相关数据：

```text
1. NTHU-DDD
2. YawDD
3. UTA-RLDD
4. 自己录制的 demo 视频
```

如果时间不够，优先级是：

```text
必做：YawDD + 自采视频
建议做：NTHU-DDD
有时间再做：UTA-RLDD
```

**每个数据集具体标什么**

### 1. YawDD

主要用于标注打哈欠。

需要标注：

```text
Yawning → is_yawning = 1
Normal → 全部为 0
Talking / Singing → 一般不算疲劳，全部为 0
```

例子：

```csv
video_id,start_frame,end_frame,subject_id,source_dataset,is_yawning,is_look_away,is_fatigued,split
yawdd_s12_clip03,300,331,s12,YawDD,1,0,0,train
```

### 2. NTHU-DDD

主要用于标注视线偏移和疲劳状态。

需要标注：

```text
looking aside / looking around → is_look_away = 1
sleepy eyes → is_fatigued = 1
nodding → is_fatigued = 1
yawning → is_yawning = 1
normal → 全部为 0
```

例子：

```csv
nthu_s01_clip01,120,151,s01,NTHU-DDD,0,1,0,train
nthu_s09_clip02,500,531,s09,NTHU-DDD,0,0,1,test
```

### 3. UTA-RLDD

主要用于标注疲劳程度。

需要标注：

```text
alertness → 全部为 0
low vigilance → is_fatigued = 1
drowsiness → is_fatigued = 1
```

例子：

```csv
uta_s07_clip04,500,531,s07,UTA-RLDD,0,0,1,train
```

### 4. 自采 demo 视频

自己录几类短视频，用来做系统演示。

建议录：

```text
正常驾驶/看镜头 → Normal
打哈欠 → Yawning
左右看/低头看别处 → Looking Around
闭眼、低头、犯困动作 → Fatigued Driving
```

对应标注：

```text
Normal → 0,0,0
Yawning → 1,0,0
Looking Around → 0,1,0
Fatigued Driving → 0,0,1
```

**2号具体要做哪些事情**

### 第一步：收集视频

把疲劳检测相关视频整理好，例如：

```text
data/fatigue_b/raw/NTHU-DDD/
data/fatigue_b/raw/YawDD/
data/fatigue_b/raw/UTA-RLDD/
data/fatigue_b/raw/self_recorded/
```

每个视频要能对应一个 `video_id`，比如：

```text
yawdd_s12_clip03.mp4
nthu_s01_clip01.mp4
uta_s07_clip04.mp4
self_s19_clip01.mp4
```

### 第二步：看视频并标注片段

2号不一定要逐帧标注，但要标出某个行为发生的帧范围：

```text
start_frame：行为开始帧
end_frame：行为结束帧
```

例如第300帧到331帧是打哈欠，就标：

```csv
yawdd_s12_clip03,300,331,s12,YawDD,1,0,0,train
```

### 第三步：统一标签格式

最终所有数据都整理成这个格式：

```csv
video_id,start_frame,end_frame,subject_id,source_dataset,is_yawning,is_look_away,is_fatigued,split
```

三个核心标签是：

```text
is_yawning：是否打哈欠
is_look_away：是否视线偏移
is_fatigued：是否疲劳驾驶
```

### 第四步：划分 train / val / test

2号要输出三份文件：

```text
data/fatigue_b/labels/train.csv
data/fatigue_b/labels/val.csv
data/fatigue_b/labels/test.csv
```

注意：**不能按帧随机划分，要按 subject_id 划分。**

也就是同一个人不能同时出现在训练集和测试集里，否则会数据泄漏。

### 第五步：写数据说明

2号还要说明：

```text
用了哪些数据集
每个数据集标了哪些类别
每类有多少条样本
train/val/test 各有多少条
标签是怎么映射的
```

**2号最终交付给5号、6号**

```text
1. 疲劳检测视频数据
2. train.csv
3. val.csv
4. test.csv
5. 标签映射说明
6. 数据统计表
```
